# BEC 513: Bioinformatics Projects

Solutions to the BEC 513 course projects, written in Python, Bash, and R. Each project has its own directory with the scripts, input files (where needed), and a `README.md`.

## Project READMEs

Each project's `README.md` covers:

- The objective of the project
- Required input files and dependencies
- The commands to run the scripts
- The output files and what they contain

## Notes

- Run scripts from the project's own directory, unless its README says otherwise.
- Check that the input files are present and the dependencies are installed before running.
